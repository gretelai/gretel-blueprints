Correlations
Correlations measure the strength and direction of relationships between all non-text variables in the dataset. This analysis helps identify potential dependencies, redundancies, and interesting associations that might influence downstream model performance or reveal insights about the data domain. Note: Correlations between categorical and numeric columns use Theil's U (uncertainty coefficient), which quantifies how much knowing one variable reduces the uncertainty about the other. This measure is asymmetric, so the correlation from column A to B may differ from B to A.
